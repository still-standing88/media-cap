# Contributing to MediaCap

For a bug report, include your operating system and version, MediaCap version, the capture source type, and steps to reproduce the issue. For CLI bugs, include the command and any relevant output from `--verbose`. Remove private device names, paths, and media before posting.

For code changes, keep the pull request focused and describe the behavior it changes. Update the relevant API documentation or examples when the public interface changes.

See the [build guide](docs/building.rst) to build MediaCap locally. Enable `--tests` and `--cli` to run the library and CLI checks. In the pull request, list the platforms and build configurations you tested.
