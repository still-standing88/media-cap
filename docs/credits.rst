Credits
=======

MediaCap is maintained by its contributors. The project uses these upstream
libraries and tools.

- `Screen Capture Lite <https://github.com/smasherprog/screen_capture_lite>`_
  for screen and window capture.
- `CameraCapture <https://github.com/wysaid/CameraCapture>`_ for camera capture.
- `miniaudio <https://miniaud.io/>`_ and
  `FlexAudio <https://github.com/Studio-Sadola/flexaudio>`_ for audio capture.
- `FFmpeg <https://ffmpeg.org/>`_ for encoding, format conversion and muxing.
- `OpenH264 <https://github.com/cisco/openh264>`_,
  `libvpx <https://chromium.googlesource.com/webm/libvpx/>`_,
  `libaom <https://aomedia.googlesource.com/aom/>`_,
  `dav1d <https://code.videolan.org/videolan/dav1d>`_,
  `Opus <https://opus-codec.org/>`_,
  `Ogg <https://xiph.org/ogg/>`_,
  `Vorbis <https://xiph.org/vorbis/>`_ and
  `LAME <https://lame.sourceforge.io/>`_ among the FFmpeg dependencies.
- `CLI11 <https://github.com/CLIUtils/CLI11>`_ for the optional command line.
- `JSON for Modern C++ <https://github.com/nlohmann/json>`_ for command requests.
- `doctest <https://github.com/doctest/doctest>`_ for the C++ test suites.
- `Doxygen <https://www.doxygen.nl/>`_, `Breathe <https://breathe.readthedocs.io/>`_
  and `Sphinx <https://www.sphinx-doc.org/>`_ for this documentation.
